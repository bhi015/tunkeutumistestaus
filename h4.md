### IDOR
(Insecure Direct Object Reference) on käyttöoikeuksien hallinnan haavoittuvuus. Se syntyy, kun sovellus käyttää käyttäjän antamaa tunnistetta suoraan tiedoston, tietokantarivin tai muun resurssin hakemiseen tarkistamatta, onko käyttäjällä oikeus kyseiseen resurssiin.

Jos tiedoston numeron vaihtaminen avaa toisen käyttäjän keskustelun, hyökkääjä voi saada haltuunsa henkilötietoja, viestejä tai kirjautumistunnuksia.

### File path traversal
haavoittuvuus jonka avulla hyökkääjä voi lukea palvelimelta tiedostoja, joihin sovelluksen ei pitäisi antaa pääsyä.

### Cross-Site Scripting
XSS on verkkosovelluksen haavoittuvuus, jossa hyökkääjä saa oman JavaScript-koodinsa suoritettua toisen käyttäjän selaimessa haavoittuvan sivuston yhteydessä.

Selain pitää koodia luotettavan sivuston sisältönä.

Jos uhrilla on ylläpitäjän oikeudet, hyökkäys voi pahimmillaan johtaa koko sovelluksen ja sen tietojen vaarantumiseen.
